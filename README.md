### RU
*Скоро здесь появится мобильное приложение для Android. Оно позволит управлять устройствами на базе ESP и с использованием прошивки ESPhome. Это значительно упростит взаимодействие с вашими умными устройствами если не используется сервер Home-Assistant и сделает их более удобными в использовании.*

### Описание
Приложение предназначено для управления устройствами умного дома (ESP32/ESP8266 и др.) через локальную сеть. Поддерживает автоматический и ручной поиск устройств, фильтрацию, отображение статусов, работу с web-интерфейсами устройств, а также гибкие настройки приватности и интерфейса.

### Основные возможности
- Поиск устройств по mDNS и ручное добавление по IP.
- Сохранение устройств с привязкой к комнатам.
- Отображение статусов (онлайн, web-интерфейс).
- Drag-and-drop сортировка устройств.
- Фильтры по комнатам, онлайн-статусу, web-интерфейсу.
- Режимы отображения: сетка и список.
- Современный UI (Material Design, анимации, pull-to-refresh).
- Настройки приватности (скрытие IP-адресов, сохранение паролей).
- Все фильтры и режимы отображения запоминаются.
- Поддержка современных сайтов: Включён JavaScript, DOM Storage, современный User-Agent.

### EN

*The mobile app for Android\is coming soon. It will allow you to manage devices based on ESP and using the ESPhome \ firmware. This will greatly simplify interaction with your smart devices if you don't use the Home-Assistant server and make them more convenient to use.*

### Description
The application is designed to control smart home devices (ESP32/ESP8266, etc.) via a local network. It supports automatic and manual device search, filtering, status display, working with device web interfaces, as well as flexible privacy and interface settings.

### Main features
- Device search by mDNS and manual addition by IP.
- Saving devices linked to rooms.
- Status display (online, web interface).
- Drag-and-drop sorting of devices.
- Filters by room, online status, web interface.
- Display modes: grid and list.
- Modern UI (Material Design, animations, pull-to-refresh).
- Privacy settings (hiding IP addresses, saving passwords).
- All filters and display modes are memorized.
- Support for modern websites: JavaScript, DOM Storage, and a modern User Agent are enabled.
